# WCD Marketplace (website)

The public website of the WCD Visual Marketplace, served by GitHub Pages at https://wcdvikash.github.io/wcd-marketplace/
(a custom domain through Cloudflare can be added in Settings → Pages).

The page is static. Searches, stock, the catalogue feed, images and staff training come from the WCD design engine
running on the company VPS (`https://srv1967127.hstgr.cloud`), whose code lives in the private repository
`wcd-marketplace-engine`. Edit `index.html` here (or let Claude edit it); every push to `main` publishes within a minute.
